Companions are optional skills that sit beside Archie. Each one installs the same way Archie does.

## Rotary Brand Voice

Rotary voice, naming, and visual identity for club, district, and zone communications.

- [Download rotary-brand-voice.zip](https://github.com/Project-Archie/rotary-archie/releases/latest/download/rotary-brand-voice.zip) for Claude, ChatGPT, and Grok.
- [Download rotary-brand-voice-v0.2.4.skill](https://github.com/Project-Archie/rotary-archie/releases/latest/download/rotary-brand-voice-v0.2.4.skill) for the Claude desktop app.
- In Claude Code: `/plugin install rotary-brand-voice@project-archie`
