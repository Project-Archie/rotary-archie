title: "Check your version and update"
---

Ask Archie: **"What version of Archie are you?"** It answers with its version number and the date it was last updated. Compare that with the version shown on the [home page](/rotary-archie/).

If yours is older, download the newest file and upload it the same way you did the first time. Your assistant replaces the old version.

- [Download rotary-archie.zip](https://github.com/Project-Archie/rotary-archie/releases/latest/download/rotary-archie.zip) for Claude, ChatGPT, and Grok.
- Claude Code users run `/plugin marketplace update project-archie`.

To hear about new versions, open the [GitHub page](https://github.com/Project-Archie/rotary-archie), click **Watch**, then **Custom**, then tick **Releases**. A GitHub account is needed for this step only.

## What the version number means

The first number is the Rotary year of the documents inside. 2026.x.x means the 2026 Rotary year, which runs July 2026 to June 2027. The third number goes up when Archie is updated during the year, for example when Rotary International publishes a new edition of the Rotary Code of Policies after a Board meeting.

## How updates happen

Once a month, the project checks My Rotary for new editions of the documents Archie carries. When one changes, a new version of Archie is published on GitHub. [Where Archie's documents come from](/rotary-archie/about/sources/) lists each document, its edition, and a link to Rotary International's copy.
